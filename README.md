# Sales and Profit Dashboard

## About the Project

This Power BI dashboard analyzes sales, cost, profit, customers, products, and transactions.

## Tools Used

- Power BI
- DAX
- Excel

## Dashboard Features

- Total Sales
- Total Profit
- Profit Margin
- Total Quantity
- Total Transactions
- Sales Trend
- Sales by Category
- Profit by Category
- Top 10 Products
- Top 10 Customers
- Product Profitability
- Customer Sales Distribution
